# NBA Neon 🏀

Сайт для тех, кто не может смотреть НБА ночью и разбирает матчи утром. Неоновый космос, значки команд в цветах клубов и собственный «индекс полезности» для каждого игрока.

**Сайт:** https://inv1nced.github.io/nba-neon/

## Что умеет

- **Матчи дня** — все игры игрового дня со счётом, статусом и самыми результативными. Стрелками можно листать дни. Время начала показывается по вашему часовому поясу.
- **Live** — если матч идёт, счёт и статистика обновляются сами каждые 20 секунд.
- **Страница матча** — счёт по четвертям, площадка со стартовыми пятёрками обеих команд, скамейка, лучшие игроки матча, сравнение команд и полный бокс-скор с сортировкой.
- **Карточка игрока** в стиле NBA 2K — рейтинг, потенциал, шесть атрибутов и радар, краткая биография (возраст, рост в см, вес в кг, драфт, колледж, сезон в лиге), график роста по сезонам и статистика за всю карьеру.
- **Разбор матча игрока** — оценка из 10, из чего она сложилась (атака, пас, подбор, защита, ошибки), что получилось и что нет, сравнение со средними за сезон.
- **Таблица** Восточной и Западной конференций с зонами плей-офф и плей-ин.
- **Страница команды** — состав, последние и ближайшие матчи.

## Как считаются рейтинги

### Индекс полезности за матч
Основа — Game Score Джона Холлинджера:

```
GS = Очки + 0.4·FGM − 0.7·FGA − 0.4·(FTA − FTM) + 0.7·ORB + 0.3·DRB + STL + 0.7·AST + 0.7·BLK − 0.4·PF − TOV
```

Он раскладывается на пять частей (атака, пас, подбор, защита, ошибки) и переводится в оценку из 10:

```
Оценка = 5.8 + 0.12·GS + 0.015·(+/−)
```

Если игрок провёл меньше 8 минут, оценка тянется к 6.0.

| Оценка | Значит |
|---|---|
| 9.0+ | шедевр |
| 8.0+ | отлично |
| 7.0+ | хорошо |
| 6.3+ | нормально |
| 5.5+ | слабовато |
| ниже | провал |

### Рейтинг игрока (OVR)
По средним за сезон: `OVR = 64 + 1.4·GS`, от 40 до 99. В начале сезона текущие матчи смешиваются с прошлым сезоном с весом `игры / (игры + 12)`, у новичков — с уровнем среднего новичка.

### Атрибуты
АТК — очки, БРС — точность (TS%) и трёхочковые, ПАС — передачи и отношение к потерям, ПДБ — подборы, ЗАЩ — перехваты, блок-шоты и подбор в защите, НАД — как редко теряет мяч.

### Потенциал
Рейтинг плюс запас по возрасту (до 19 лет +14, 22 года +8, 25 лет +3, после 27 — 0) и небольшая прибавка, если молодой игрок вырос за сезон.

## Как устроено

Обычные HTML, CSS и JavaScript-модули, без сборки и зависимостей — поэтому сайт работает прямо на GitHub Pages.

```
index.html
css/style.css        оформление
js/app.js            маршруты (#/game/…, #/player/…) и автообновление
js/api.js            загрузка данных ESPN, кэш, разбор ответов
js/rating.js         все формулы
js/teams.js          русские названия команд, цвета и неон
js/ui.js             общие элементы интерфейса
js/view-*.js         страницы: матчи, матч, игрок, таблица, команда
js/bg.js             космический фон на canvas
```

Запустить локально:

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Данные

Открытый (неофициальный) API ESPN, запросы идут прямо из браузера. Значки команд — собственный дизайн по аббревиатурам и цветам клубов, официальные логотипы и фото игроков не используются. Проект фанатский и не связан с НБА или ESPN.
